# Bitbucket Pipelines Pipe: <pipe_name>

This pipe uploads code coverage reports to CodeScene. It supports various formats such as `lcov`, `cobertura`, and `jacoco`.
The pipe requires a valid CodeScene access token, which can be set in the repository settings.

For more information, visit the [CodeScene documentation](https://codescene.io/docs/integrations/cli-coverage.html#client-setup).

## YAML Definition

Add the following snippet to the script section of your `bitbucket-pipelines.yml` file:

```yaml
- step:
      name: Upload Coverage
      script:
          - pipe: jens-fap/codescene-coverage-upload:0.1.0
            variables:
                FORMAT: 'lcov'
                METRIC: 'line-coverage'
                COVERAGE_FILE: 'path/to/file'
                # CS_ACCESS_TOKEN: "$CS_ACCESS_TOKEN" this is set using
```

## Variables

The variables are exactly the same as the actual cs-coverage tool: [https://codescene.io/docs/integrations/cli-coverage.html#client-setup]. I just added a version bool to the variables to enable version output.

```yaml
FORMAT: # format of the coverage file you want to upload (see [docs](https://codescene.io/docs/integrations/setting-up-code-coverage.html))
METRIC: # metric you want to upload (see [docs](https://codescene.io/docs/integrations/setting-up-code-coverage.html))
COVERAGE_FILE: # file you want to upload
CS_ACCESS_TOKEN: # set this to the token generated by codescene
VERSION: false
```
